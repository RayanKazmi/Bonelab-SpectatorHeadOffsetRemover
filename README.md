# Spectator Head Offset Remover
This is a Bonelab code mod that remove the head offset added by marrow (to prevent your own face being in view) from the spectator camera on pcvr. It works by making a clone of your avatar and displaying it instead of the offset avatar. The clone is only viable on the pc side so your vr gameplay is uninterrupted and you can use 3rd person camera mods such as wide eye or advance gopro to record yourself without the offset!
